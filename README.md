## ✨ About

**AskGPT** is an AI chatbot created and developed by **Pushpraj Kumar**.

It is built to provide a simple, fast, and user-friendly
conversation experience for questions ranging from general knowledge
to programming and educational topics.

## 🚀 Features

- 🤖 AI-powered conversations
- 💬 Natural and contextual responses
- 🔍 Current information and web search support
- 💻 Programming & coding assistance
- 📚 Educational and general knowledge support
- 📎 File and image support
- 🌙 Modern dark interface
- ⚡ Fast and responsive UI

## 🛠️ Tech Stack

**Frontend**
- React
- TypeScript
- Vite
- Tailwind CSS

**Backend**
- Node.js
- Express.js
- Google Gemini API

**Deployment**
- Vercel — Frontend
- Render — Backend
